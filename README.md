# 本地音乐器 macOS 客户端

这是一个原生 macOS 音乐播放器客户端，使用 AppKit + AVFoundation 实现，不依赖网页运行。

## 构建

```bash
bash build-mac.sh
```

构建完成后会生成：

```text
build/本地音乐器.app
```

## 功能

- 从本地文件夹或 iCloud Drive 文件夹导入音乐。
- 可一次选择多个文件夹，也可多次混合添加来源。
- 支持 `mp3`、`m4a`、`aac`、`wav`、`flac`、`ogg` 等音频文件。
- 音乐列表、当前播放、最近播放、文件夹管理。
- 可在资料库中按指定音乐目录筛选歌曲，并让上一首/下一首按当前筛选结果切换。
- 当前播放卡片可进入播放详情。
- 当前播放和详情页都支持拖动播放进度。
- 支持随机播放、顺序播放、列表循环、单曲循环。
- 支持同名 `.lrc` 歌词，高亮当前播放歌词。
- 支持同名图片或 `cover/folder/album.jpg/png/webp` 作为专辑封面。
